# UFOT 用户指南

面向 UFOT 网页端（apps/client，黑白极简界面）的日常使用者。

## 登录（四种方式）

打开站点后，在登录页选择任一方式：

- **手机号**：输入手机号（如 `+8613800138000`）→ 收到 6 位验证码 → 输入即登录（新号码自动注册）
- **邮箱**：输入邮箱 → 收到登录链接 → 在邮箱里点击链接 → 回到页面即自动完成登录
- **账号密码**：已设置过密码的账号，输入账号 + 密码登录
- **游客模式**：无需注册直接体验；之后可在设置里设置密码，升级为正式账号

## 会话

- **新建会话**：点「新建会话」，选择成员 ID 可建群聊；留空成员则创建仅自己的会话
- **搜索**：顶部搜索框按标题过滤会话
- **置顶 / 静音**：会话列表中以标签显示状态；置顶会话排在最前
- **未读**：每会话显示未读数，超过 99 显示「99+」
- **单聊 / 群聊**：列表中以「单聊」「群聊」标签区分

## 聊天

- **发送**：输入消息回车发送；点「+」添加附件（图片/音频/文件，自动上传）
- **回复**：消息菜单选「回复」，输入框上方出现引用条，可随时取消
- **编辑**：对自己发出的消息选「编辑」，修改后显示「已编辑」
- **撤回 / 删除**：消息菜单操作；撤回后显示「消息已撤回」
- **转发**：选「转发」输入目标会话 ID
- **复制**：复制消息文本
- **正在输入**：对方正在输入时列表中显示「正在输入…」

## 设置

- **个人资料**：修改昵称，实时保存
- **密码**：设置/修改密码（至少 8 位）
- **主题**：亮色 / 暗色 / 跟随系统
- **清除缓存**：只清除本设备上的消息与会话缓存，不影响服务器数据
- **退出登录**：登出当前设备

## 常见问题

**收不到验证码？** 同一号码每分钟限 1 条、每小时限 5 条、每天限 10 条；仍收不到请联系管理员。

**消息发不出去？** 发送失败的消息可点「重试」；检查网络后重试即可。

**浏览器推送通知**：在设置里开启；需要站点支持 HTTPS 且浏览器授权通知权限。
