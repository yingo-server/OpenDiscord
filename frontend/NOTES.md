# UFOT Web 客户端 — 实测记录

> 本文记录契约与实测差异、当前降级行为。**以实测为准**；不再写“待验证”的结论。

## A. 契约与实测差异

### A1. CORS：只反射 http(s) Origin

`Origin: null` 与 `minis://` 不返回 CORS 头；`http(s)://...` 正常反射并允许凭证。前端必须从 http(s) 源运行。

### A2. 跨源 Cookie 与 WS

`access_token` Cookie 是 `SameSite=Lax; HttpOnly`。跨站请求不会携带；WS 握手响应不回显 `Sec-WebSocket-Protocol`，浏览器判握手失败。结论：跨源浏览器客户端不可行，部署必须同域反代。

### A3. 用户层数据通道

客户端可通过 930 / 940 请求数据层；回执 931 / 941 按 request_id 配对。会话列表仍依赖事件累积；历史分页（920）对用户端不可达，只能用 kind 8 SYNC 从 `sinceSeq=0` 补拉。

### A4. 会话列举 / 用户检索

服务端不提供用户端会话列举；会话列表靠 `CONV_PAYLOAD` 累积。列表底部保留“现有会话 ID”入口，便于直接进入已知会话。

### A5. 管理面

`/api/v1/*` 默认只监听 `127.0.0.1:7781`。当前前端没有管理台页面，这一项只影响独立 REST 客户端。

### A6. 验收记录

| 项目 | 结果 |
|---|---|
| guest 登录、刷新恢复 | 通过 |
| 375px 不破版、亮/暗主题 | 通过 |
| PING/PONG、ERROR 帧 | 通过 |
| MSG_SEND → ACK → MSG_NEW → SYNC | 未闭环，列为当前可用性阻塞 |

## B. 当前页面

登录（游客/密码）、会话、设置。`phone` / `email` 只保留服务端能力，前端不展示。
